# Experience Copilot learning guide

Open [learning-guide.html](learning-guide.html) in a browser after downloading or cloning the project.
The file is self-contained: no server, network access, credentials or model calls are required.
GitHub's file viewer shows HTML source; use a local browser to experience the guide.

The guide includes 13 chapters, four accessible SVG diagrams, a step-by-step question walkthrough,
a clickable module map, parameter explanations, a learning-only configuration sandbox, change recipes,
document-format adapter design, evaluation practices and the distinction between indexing and training.
Use its Print / save PDF button for a print layout. Narrow screens can scroll the diagram panels;
labels are deliberately kept readable rather than shrinking entire workflows into tiny text.

Code/configuration snapshot: November 2, 2026. Personal library status described in the guide is a
snapshot, not a live dashboard. Existing test counts are historical observations, not fresh benchmarks
run by opening the guide. Personal source text, keys and private evaluation answers are not embedded.

Related references: [development plan](PLAN.md), [testing guide](TESTING.md).
