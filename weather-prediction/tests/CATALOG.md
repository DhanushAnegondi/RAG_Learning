# Test catalog

All tests run without the network (fixtures, fake HTTP session) against a real Postgres: the
Compose service's `weatherwise_test` database (`make up`; `tests/conftest.py`). Sprint 01-02 tests
were written on DuckDB and ported in sprint 03 unchanged in meaning (connection fixture,
`psycopg.Error`, one type name). RED = seen failing before
the code existed; evidence in `results/<sprint>/run/red*.out`. GREEN in `green.out`.
One row per test function (parametrized cases share a row).
Mutation evidence: `results/sprint-04/run/mutation.out` (sprint-04 files) and
`results/sprint-03/run/mutation.out` (`make mutate`, Postgres, every mutant of
sprints 01-03). `results/sprint-02/run/mutation.out` is the frozen DuckDB run of an earlier list.
